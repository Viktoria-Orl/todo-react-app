# Todo React App

🌐 [Live Demo](https://viktoria-orl.github.io/todo-react-app/)

A simple task manager built with **React**. This application allows users to manage their daily tasks with ease — by adding, editing, deleting, and marking tasks as completed. It uses a mock REST API powered by `json-server` for data persistence and simulates interaction with a real backend.

## Features

- Add, delete, and update tasks
- Mark tasks as completed or active
- Display of completed and active task counts
- Data persistence using `json-server`
- Clean and minimal UI with intuitive interactions

## Technologies Used
- React
- JavaScript (ES6+)
- HTML5
- CSS3 (Flexbox)
- json-server (mock backend)
